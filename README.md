# CareerConnect – Student & Placement Management System

CareerConnect is a student and placement management system developed to organize student information, company details, job opportunities, and placement records.

The project combines a web-based interface with Python data analysis, SQL database concepts, and Power BI visualization.

## 🚀 Features

- Student information management
- Company and job listing
- Student placement records
- Student search functionality
- Job application interface
- Placement status tracking
- Python-based data analysis
- SQL queries for student and placement analysis
- Power BI dashboard for data visualization

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Pandas
- SQL / MySQL
- Power BI
- Git & GitHub
